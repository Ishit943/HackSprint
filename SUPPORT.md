## 3. Frequently Asked Questions (FAQ)

- **Q: Do I need a live Supabase account to test the project?**  
  **A:** No! Monster Match features a complete mock service layer in `js/api.js` powered by `localStorage`. It comes pre-loaded with 6 diverse student personas.
- **Q: Does WhatsApp click-to-chat require payment or Meta approval?**  
  **A:** No! Our Tier-1 messaging pipeline uses public `https://wa.me/` deep links which work instantly on mobile and desktop without any API fee or developer registration.
