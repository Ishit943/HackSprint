# 🎃 Monster Match — Feature List

> Complete breakdown of implemented and planned features for Monster Match v0.9.0.

---

## ✅ Implemented Features

### 🎯 Core Matching Engine

#### ✅ Smart Match Algorithm
- **100-point scoring system** with four weighted components:
  - 🔧 **Skill Overlap** — Up to **70 points** based on proportion of required/desired skills shared
  - ⏰ **Availability Overlap** — Up to **15 points** based on weekly hours commitment alignment
  - 💡 **Interest Overlap** — Up to **10 points** based on domain category intersection (AI, Web3, Fintech, etc.)
  - ⭐ **Proficiency Bonus** — Up to **5 points** for `advanced`-rated skills
- Match score badge rendered live on every student card
- Scores computed entirely client-side — no round-trip required

#### ✅ Skill-Based Search with AND/OR Filter Logic
- Free-text skill filter input with tag-pill UI
- Toggle between **AND** mode (student must have ALL selected skills) and **OR** mode (student has ANY selected skill)
- Filters apply reactively — no page reload
- Combined with availability and interest range sliders

#### ✅ Complementary Teammate Discovery
- Detects **skill gaps** in the current team composition
- Surfaces students who fill those gaps rather than duplicating existing skills
- E.g., if team has Backend (Node.js/Python) → prioritises candidates with Frontend (React/Vue) and Design (Figma/UI)

### 👤 Identity & Profile

#### ✅ Monster Avatar System (DiceBear Bottts)
- Every student receives a **unique, deterministic monster mascot** generated by DiceBear Bottts API
- Seed = user ID → same user always gets the same monster, no manual upload needed
- Fallback to styled initials bubble if DiceBear API is offline
- Avoids real-photo privacy concerns in a college context

#### ✅ Profile Completeness Meter
- **8 weighted fields** aggregated into a 0–100% completeness score:
  | Field | Weight |
  |---|---|
  | Full Name | 15% |
  | Profile Avatar / Monster Mascot | 10% |
  | College & Academic Info | 10% |
  | Branch & Year | 10% |
  | Detailed Bio (> 20 characters) | 15% |
  | Contact Details (Phone / WhatsApp) | 15% |
  | Minimum 3 Technical Skills with Proficiency | 15% |
  | Portfolio / GitHub Links | 10% |
- Inline prompt badges suggest next improvement: *"Add 2 more skills to reach 100% profile strength!"*
- Progress bar with Halloween gradient styling

#### ✅ College Email Verification
- Recognises `.ac.in`, `.edu`, and affiliated university email domains
- Automatically grants **🎓 Verified Student** badge on the profile card
- Zero third-party OAuth dependency — pure domain regex check

### 🔗 Connection & Privacy System

#### ✅ Connection Request System with Message Notes
- Any student can send a connection request to another with an optional personalised note
- Request enters `pending` state and is visible in the receiver's **Connections** inbox
- Receiver can **Accept** or **Decline**

#### ✅ Privacy-Gated Contact Unlock
- **WhatsApp number and phone are never exposed** in public listings, search results, or DOM responses
- Contact details are unlocked **only** when both parties have a mutually accepted connection
- Enforced at the data-query level — not just UI visibility

#### ✅ WhatsApp Click-to-Chat Integration (`wa.me`)
- On accepted connection, a **"Chat on WhatsApp 💬"** button appears
- Cleans phone numbers to international format (strips non-digits, prepends country code)
- Formats a context-aware pre-filled message:
  ```
  https://wa.me/<phone>?text=Hi%20{name}%2C%20I%20saw%20your%20profile%20on%20Monster%20Match...
  ```
- 100% free — no Meta Business approval, no API key, works instantly on mobile and desktop

### 🗂️ Projects Directory

#### ✅ Projects Directory with Role Slot Management
- Teams can post projects with title, description, domain tags, and timeline
- Each project defines **role slots**: `{ title, slots (count), required skills[] }`
- Role slots show remaining vacancies — filled slots are visually marked
- Students can view project details and send a "Join Request" (maps to a connection request to the team lead)

## 📋 Planned Features

### 🤖 AI & Automation

#### 📋 AI Resume Parser Agent
- Upload PDF résumé → auto-extract technical skills, hackathon wins, GitHub repos
- Powered by a serverless edge function calling a document-parsing LLM
- Populates skill fields without manual entry

#### 📋 WhatsApp Cloud API Notifications (Phase 8)
- Triggered on `connection_requests.status = 'accepted'` Supabase webhook
- Delivers automated template alerts (`connection_request_alert`, `request_accepted`) via Meta Graph API
- Requires Meta Business Verification (pending approval)

#### 📋 Voice Pitch — 30-Second Audio Profiles
- Students record a short audio intro summarising skills and goals
- Audio transcribed and analysed for soft-skill keywords
- Displayed on profile card with waveform visualisation

#### 📋 Hackathon Schedule Bot
- Integrates Google Calendar / Devpost deadlines
- Notifies teammates about upcoming sprint milestones and submission windows
- Configurable per-project reminders
